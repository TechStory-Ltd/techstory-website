# Tech Story website

Static website for `techstory.org.uk`, ready to publish with GitHub Pages.

## Deploy on GitHub Pages

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to **Pages**.
4. Set the source to the `main` branch and the repository root.
5. Make sure the custom domain is `techstory.org.uk`.

The `CNAME` file is already included for the custom domain.
